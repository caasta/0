# AppRebrands landing lookalike

Faithful visual/UI recreation of the [apprebrands.com](https://apprebrands.com/) landing page for local demo purposes.

## Stack

- Vite + React + TypeScript
- Remix Icon
- Inter (matches the live storefront)

## Run

```bash
cd web
npm install
npm run dev
```

Then open the URL Vite prints (usually `http://localhost:5173`).

## Build

```bash
cd web
npm run build
npm run preview
```

## Notes

- Product and hero imagery are original SVG placeholders (not scraped from the live site).
- Interactive store/auth/cart flows are UI-only anchors for this demo.
