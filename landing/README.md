# AppRebrands landing lookalike

Faithful visual/UI recreation of [apprebrands.com](https://apprebrands.com/) for local demo use.

## Run

```bash
cd landing
npm install
npm run dev
```

Then open the URL Vite prints (usually `http://localhost:5173`).

## Build

```bash
cd landing
npm run build
npm run preview
```

## Notes

- Placeholder SVG imagery/icons are used instead of redistributing original product/media assets.
- Contact form is local-only and does not submit to a backend.
- Theme toggle and language menu are UI-faithful demos.
